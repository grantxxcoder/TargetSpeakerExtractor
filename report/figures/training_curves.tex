  \caption{Training (dashed) and validation (solid) scores per epoch, counted from zero, for the baseline (left) and the extension (right). Middle: output level on target-absent clips relative to the mixture, $L_\textup{abs}$ (lower is quieter); the dotted line is the \SI{-10}{dB} silence bar, and shaded epochs fail it. Bottom: word error rate on the 103 validation trials with both speakers present (lower is better). Each filled diamond is one run of the live judge on the same audio, labelled with the mean of the runs at that epoch; each hollow diamond is Whisper \texttt{small.en} scoring that saved epoch on the same 103 trials; the grey line is the in-training Whisper \texttt{small.en} check on 40 validation clips, which was not run for the baseline. The solid vertical line marks the chosen epoch, the blue dashed line the extension's lowest validation loss, and the grey dotted line where the extension's training resumed in a second session.}
